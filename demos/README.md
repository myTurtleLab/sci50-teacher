# Ready-made demonstrations: the 12 DSE programs

Demonstration files for the PracCalc teacher edition (https://teach.pwc.hk). There is one file for each of the 12 DSE programs in PracCalc's Program Library, P1 to P12. Import a file and press Play: the calculator shows every key needed to type the program in, then runs it once with a worked example. You do not have to key a long program into a real calculator in front of the class.

## What is in this folder

| File | What it is |
| --- | --- |
| `PracCalc P01 … P12 …_key-in demo_v1.json` | 12 demonstration files, one per program (table below) |
| `PracCalc DSE programs_key-in demos_v1.zip` | All 12 `.json` files in one zip |
| `README.md` | This page |

Each demonstration:

1. Starts from a cleared screen and an empty program memory.
2. Opens the program editor for P1 in the program's mode: **MODE 6 1 1**, then **1** (COMP) or **2** (CMPLX).
3. Types the program key by key. The keys are the same as the Program Library's Key-in instructions, so students see the same steps in the app.
4. Presses **AC** to save the program, chooses the calculation mode, and runs the program with **Prog 1**.
5. Types the worked example's values at each prompt, and shows each answer.
6. When an answer is complex (P8, P9 and P11), the display shows its real part first. The demonstration then presses **SHIFT EXE** (Re⇔Im) to show the imaginary part, and **SHIFT EXE** again to go back.

## How to use them

### 1. Download

- **All 12 in one click:** [PracCalc DSE programs_key-in demos_v1.zip](https://teach.pwc.hk/demos/PracCalc%20DSE%20programs_key-in%20demos_v1.zip). Unzip it before use: on Windows, right-click the zip and choose **Extract All**; on a Mac, double-click it.
- **One program:** click its file in the table above, then the **Download raw file** button (the arrow at the top right of the file view).

### 2. Open the teacher edition

Open https://teach.pwc.hk in Chrome or Edge on a computer, or on a tablet held sideways. The window must be at least 600 pixels wide, and the computer must be online.

### 3. Import the file

1. Press **Import…** in the key record beside the calculator. You can also use Menu (⋮) → **Teacher demonstration** → **Import demonstration…**.
2. Choose the `.json` file.
3. A preview opens. It says the file was checked and played through on a test calculator, and shows the title, the number of steps and "Programs: Not included". Nothing has changed yet.
4. Press **Load demonstration**. If the key record already holds your own steps, you are asked to **Replace** them. Export them first if you want to keep them.

### 4. Play it for the class

| Action | Button | Computer key |
| --- | --- | --- |
| Play or pause | Play / Pause | F9 |
| One key at a time | Step | Ctrl+→ |
| Back to your own calculator | Stop | Shift+F9 |

- The key being pressed lights up on the calculator and in the key record, with its step number.
- Change the speed from 0.2 to 2.5 seconds a step in Menu (⋮) → **Teacher demonstration**. For the long programs (P3 and P7), use Step or a faster speed.
- **Copy text** gives all the steps as plain text, to paste into a worksheet or your class page.

### 5. Your own calculator is not changed

The demonstration plays from its own start: a cleared screen and an empty program memory. Stop puts your calculator back exactly as it was, with your own memory and programs. Nothing in the file is run as code; the teacher edition checks every file before it changes anything.

## Students

The keys are the same as the Program Library's Key-in instructions in PracCalc. Students can repeat them on the free student version (https://myturtlelab.github.io/sci50-html/), or on their own calculator. The demonstrations start with P1 empty. If P1 on a student's calculator already holds a program, delete it first with **MODE 6 3 1**, as the Key-in instructions say. Otherwise the new keys are added to the old program.

## Version

Made with PracCalc 0.3.54 and teacher edition 0.1.9, 25 November 2026. If a later version of the calculator would show a different answer, the Import preview says so before anything changes.
